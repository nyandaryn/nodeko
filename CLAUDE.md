# nodeko — заметки для ИИ-агентов

Личная панель мониторинга (хаб + агенты + веб). Обзор и безопасность — `README.md`.
Репозиторий публичный: никаких адресов, имён хостов, токенов и прочих деталей реальной инфраструктуры в коде, тестах, моках и доках — только вымышленные (`example.com`, `atlas`, `/home/deploy`). Где развёрнуто у владельца — в `CLAUDE.local.md` (не в git).

## Карта кода
- `src/shared/protocol.ts` — сообщения агент↔хаб, лимиты, шаблон ошибок логов. Менять совместимо: агенты обновляются не мгновенно.
- `src/shared/secure.ts` — рукопожатие и шифрованные кадры. Любая правка = новая версия протокола (`PROTOCOL_VERSION`, `v` в hs1) + тесты `secure.test.ts`.
- `src/shared/api.ts` — контракт REST (шапка файла — список эндпоинтов). Веб и MCP опираются на него.
- База знаний (заметки): `src/shared/notes.ts` — валидация, поиск, точечные правки, детектор секретов (чистые функции, общие с вебом и моком); `src/hub/notes.ts` — БД и версии; `src/hub/notes-io.ts` — файлы с frontmatter для `notes:import/export`.
- `src/hub/` — `main.ts` (запуск), `db.ts` (схема/миграции: только добавлять новые элементы в `MIGRATIONS`), `agents.ts` (WS), `ingest.ts` (снимки), `services.ts`/`checks.ts`/`monitor.ts` (статусы, переходы, уведомления), `maintenance.ts` (свёртка метрик tier0→1→2, очистка), `queries.ts` (чтение для API), `http/` (роуты, auth, статика, установка агента), `mcp.ts`, `auth/`, `cli.ts`.
- `src/agent/` — `main.ts` (подключение), `collector.ts`, `collect/*` (сборщики, парсеры — чистые функции с тестами).
- `web/` — React-интерфейс; `scripts/mock-hub.ts` — мок API для разработки UI.

## Правила
- Агент не должен исполнять ничего, что пришло от хаба (кроме HTTP/TCP-проверок по декларативному описанию).
- Данные агента на хабе — недоверенные: санитайзинг в `ingest.ts`, проверка `runner` у результатов проверок.
- Секреты (токен бота, токены, сессии) не логировать и не отдавать в API; токен бота — только запись.
- Заметки базы знаний не хранят секретов: новый вид секрета — паттерн в `findSecrets` + тест (и ложные срабатывания — тоже тестом).
- Версию агента (`AGENT_VERSION`) поднимать при изменениях агента: хаб показывает «агент устарел».
- Проверка перед выкаткой: `bun test && bun run typecheck && bun run build`.
